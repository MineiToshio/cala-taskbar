# Cala 1.0.1

Esta versión añade medidas internas de tiempo en Correo, para poder hacer más rápido el Correo más adelante.

- Los tiempos se guardan solo en el registro de depuración local de tu Mac. No se envían a ningún sitio y no se registra el contenido de los mensajes.
- Correo funciona exactamente igual que antes.
