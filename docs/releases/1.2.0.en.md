# Cala 1.2.0

- Docker is now in the tray. See whether it’s on or off and turn it on or off with one click. Manage containers grouped by project: start, stop or restart them, open a port in your browser, view logs or open a terminal inside. Use the Images and Volumes tabs to remove what you no longer need; Cala always asks first. Works with Docker Desktop, Colima, OrbStack, Podman and Rancher Desktop, without requiring Docker Desktop. If you use more than one engine with Docker contexts, you can switch between them from the panel. If Docker isn’t installed, the item doesn’t appear.
- Hiding a tray item in Settings → Tray now stops it completely. Mail stops syncing; Claude and Codex stop checking usage and sending alerts; CPU and memory stop measuring; and Wi‑Fi, battery, volume and other system details stop being read. Show the item again and it resumes automatically.
- Turning off the tray now also frees the memory used to display emails.
