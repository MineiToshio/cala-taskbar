# Cala 1.2.0

- Docker llega a la bandeja. Comprueba si está activo y enciéndelo o apágalo con un clic. Administra los contenedores agrupados por proyecto: inícialos, detenlos o reinícialos, abre un puerto en el navegador, consulta los logs o abre una terminal dentro. En las pestañas Imágenes y Volúmenes puedes eliminar lo que ya no uses; Cala siempre te lo pregunta antes. Funciona con Docker Desktop, Colima, OrbStack, Podman y Rancher Desktop, sin necesidad de Docker Desktop. Si tienes más de un motor, puedes cambiar entre ellos desde el panel. Si no tienes Docker instalado, no verás este elemento.
- Al ocultar un elemento en Configuración → Bandeja, ahora se detiene por completo. Correo deja de sincronizar; Claude y Codex dejan de consultar el uso y enviar avisos; CPU y memoria deja de medir; y Cala deja de leer datos como la conexión Wi‑Fi, la batería o el volumen. Cuando vuelvas a mostrar el elemento, se reanudará automáticamente.
- Al apagar la bandeja, también se libera la memoria que se usaba para mostrar los correos.
