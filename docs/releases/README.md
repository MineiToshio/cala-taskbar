# Notas de release

Para cada versión de `VERSION`, escribe `<versión>.en.md` y `<versión>.es.md`. Haz commit de ambos archivos junto con el cambio de versión. El release incluye los dos textos en el manifiesto firmado y en el borrador de GitHub.

Cada archivo debe contener las novedades para los usuarios, en UTF-8 y con un máximo de 8 KB. Cala muestra texto y Markdown en línea. Usa las notas en GitHub para enlazar al contexto completo.
