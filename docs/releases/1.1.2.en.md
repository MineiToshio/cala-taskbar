# Cala 1.1.2

- The new-version notice is now subtle: a small icon next to the tray, the same size as the others, with the version number. Hover to see what it is; click to install it, leave it for later or skip it.
- The usage forecast gives a first estimate from the start and refines it with your real usage over the first days.
- The forecast no longer jumps while it recalculates for a new reading.
