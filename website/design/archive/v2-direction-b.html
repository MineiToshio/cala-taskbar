Install Cala

The same universal app runs on Apple silicon and Intel Macs with macOS 14 or later.

One command

Recommended

Open Terminal with Spotlight (⌘ + Space), paste this command and press Return.

Terminal
$curl -fsSL https://raw.githubusercontent.com/MineiToshio/cala-taskbar/main/scripts/get-cala.sh | bash

It downloads the latest release, checks its SHA-256 checksum, installs Cala in Applications and opens it. This method skips the one-time macOS prompt. Run it again to update and keep your settings.

Read the install script

Download the disk image

Download DMG
  1. Download Cala-x.y.z.dmg from GitHub.
  2. Open the DMG and drag Cala into Applications.
  3. Allow Cala to open once. After that it opens normally.

macOS 15 (Sequoia) or later

  1. Double-click Cala in Applications. When you see the verification message, click Done.
  2. In System Settings, open Privacy & Security and scroll to the bottom.
  3. Click Open Anyway next to the Cala notice and enter your password.
  4. Open Cala again and choose Open Anyway.

macOS 14 (Sonoma)

In Applications, right-click Cala, choose Open, then confirm with Open again.

Allow it from Terminal
xattr -dr com.apple.quarantine /Applications/Cala.app

Follow Cala’s four short welcome steps. You can skip any of them.

Permissions, one at a time

Cala explains each request and takes you to the right place in System Settings. You can skip any permission and still use the rest of the app.

To grant them later, right-click an empty part of the bar and open Settings → Permissions.

Privacy and security

Cala requires no account and uses no analytics. Window previews and calendar events are processed on your Mac.

What leaves your Mac and when

  • Claude and Codex quotas

    On by default, the indicator uses your existing Claude Code and Codex credentials. It checks Claude’s quota with Anthropic. For Codex it uses the local codex app-server process or contacts OpenAI directly through ChatGPT.

    Claude Code can send Haiku a short “ok” prompt to renew an expired token, using a little quota. Turn off the Usage switch in Cala’s Settings → Usage.

  • Reports

    If reporting is configured, Cala sends reports to Sentry. You can review your message, optional email and attachments before sending. Even with “Include technical information” off, reports include your Mac model, macOS version, permission status and some settings. The detailed diagnostic attachment is optional.

    Cala asks before sending crash reports by default. With automatic sending enabled, Cala sends the .ips file and diagnostics the next time it opens.

  • Actions you start

    Join opens the video call link. The Terminal installer downloads Cala from GitHub and verifies the published SHA-256 checksum.

Is it safe to install?

The source is public. You can read it, inspect the installer and build Cala yourself.

Cala is distributed without an Apple Developer ID signature. The Apple Developer Program costs 99 USD a year. If you use the DMG, macOS asks you to allow Cala to open once.

Frequently asked questions

What Macs can run Cala?

Cala runs on macOS 14 (Sonoma) or later. The download is universal for Apple silicon and Intel.

How do I update Cala?

Run the install command again, or download the new DMG and replace Cala in Applications. Your settings and permissions are kept.

How do I uninstall it?

In Cala, go to Settings → Advanced → Uninstall Cala. It restores the Dock and menu bar, removes the login item, deletes Cala’s settings and moves it to the Trash. You can remove its permissions in System Settings → Privacy & Security.

Why does macOS block the DMG install?

Cala is distributed without an Apple Developer ID signature. macOS asks for your approval the first time you open it from Applications.
