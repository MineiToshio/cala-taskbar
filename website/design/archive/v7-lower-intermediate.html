Install Cala

The same universal app runs on Apple silicon and Intel Macs with macOS 14 or later.

One command

Open Terminal with Spotlight (⌘ + Space), paste this command and press Return.

Recommended
Terminal
~ %curl -fsSL https://raw.githubusercontent.com/MineiToshio/cala-taskbar/main/scripts/get-cala.sh | bash

It downloads the latest release, checks its SHA-256 checksum, installs Cala in Applications and opens it. This method skips the one-time macOS prompt. Run it again to update and keep your settings.

Permissions, one at a time

Cala explains each request and takes you to the right place in System Settings. You can skip any permission and still use the rest of the app.

Permission preview Toggle a permission to see what changes.
  • Accessibility

    See, focus, minimize and close windows. It also enables Option + Tab.

    If you skip it The bar still opens apps, without window controls.
  • Screen Recording

    Shows window thumbnails. Cala never saves a recording or sends your screen.

    If you skip it Window thumbnails stay off.
  • Calendar

    Shows upcoming events and the Join button.

    If you skip it The clock opens without events.
  • Location

    macOS needs it to show Wi-Fi network names.

    If you skip it Network names stay hidden.
  • Bluetooth

    Lists and connects paired devices.

    If you skip it Devices aren’t listed.
  • Control Finder

    Counts and empties the Trash, and restarts your Mac on request.

    If you skip it Those actions are unavailable in Cala.
  • Notifications

    Shows Claude or Codex quota alerts.

    If you skip it You won’t see quota alerts.

When macOS asks

For Accessibility and Screen Recording, turn on Cala in the list macOS opens using Touch ID or your password. If macOS offers Quit & Reopen after Screen Recording, accept it.

To grant them later, right-click an empty part of the bar and open Settings → Permissions.

Technical details

Claude and Codex quotas

Cala reads local quota data when available. For remote reads, it queries Anthropic using the Claude Code access token. Codex uses its local app-server or the ChatGPT endpoint with its existing token and account ID. Claude Code may send a short “ok” prompt to Haiku to renew an expired token, which uses a little quota.

Reports

If reporting is configured, Cala sends reports to Sentry. You can review your message, optional email and attachments before sending. Even with “Include technical information” off, reports include your Mac model, macOS version, permission status and some settings. The detailed diagnostic attachment is optional.

Cala asks before sending crash reports by default. With automatic sending enabled, Cala sends the .ips file and diagnostics the next time it opens.

Cala redacts the home folder, user name, Mac name and email addresses in diagnostics. If sending is unavailable in your build, you can copy the report and paste it into an issue.

Is it safe to install?

Public source

The source is public. You can read it, inspect the installer and build Cala yourself.

View the source on GitHub

No Cala account

Use the bar without signing up. Quotas and calendars use accounts you already have.

Apple Developer ID

Cala ships without a Developer ID signature because Apple’s program costs US$99 a year. macOS asks once when you open the DMG version.

SHA-256 check

The Terminal installer compares the DMG’s checksum with the one published for that release before installing.

Frequently asked questions

Installation

What Macs can run Cala?

Cala runs on macOS 14 (Sonoma) or later. The download is universal for Apple silicon and Intel.

Why does macOS block the DMG install?

Cala is distributed without an Apple Developer ID signature. macOS asks for your approval the first time you open it from Applications.

See the steps for your version of macOS
How do I update Cala?

Run the install command again, or download the new DMG and replace Cala in Applications. Your settings and permissions are kept.

App and license

How do I uninstall it?

In Cala, go to Settings → Advanced → Uninstall Cala. It restores the Dock and menu bar, removes the login item, deletes Cala’s settings and moves it to the Trash. You can remove its permissions in System Settings → Privacy & Security.
